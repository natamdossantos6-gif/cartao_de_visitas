# 💼 Cartão de Visitas Digital

Projeto desenvolvido durante a disciplina de **Front-end** do curso de **Análise e Desenvolvimento de Sistemas (ADS)** na Cruzeiro do Sul, com o objetivo de aplicar na prática os fundamentos de HTML na construção de uma interface simples e funcional.

## 🎯 Sobre o projeto

Este cartão de visitas digital foi criado como exercício introdutório de estruturação de páginas web, explorando boas práticas de marcação semântica e organização de conteúdo em HTML puro.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estruturação e semântica do conteúdo

## 📚 Contexto acadêmico

Projeto desenvolvido como parte do meu processo de aprendizado em desenvolvimento web, dentro da grade curricular de ADS. Faz parte de uma série de exercícios práticos que venho construindo como portfólio para futuras oportunidades de estágio.

## 🚀 Como visualizar

1. Clone este repositório
2. Abra o arquivo `cartao_de_visitas.html` em qualquer navegador
